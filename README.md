# RP Overlay

Окно с командной строкой и биндерами, которое открывается поверх игры по клавише (по умолчанию F5).

## Как пользоваться
1. Запусти `RP-Overlay.exe`. Программа спрячется в трей (значок возле часов).
2. В игре нажми **F5**. Окно откроется, курсор уже в строке.
3. Напиши команду или часть названия биндера и нажми **Enter**. Текст попадёт в буфер обмена, окно закроется.
4. В игре открой чат и нажми **Ctrl+V**, затем Enter.
5. Если в биндере несколько строк: открой оверлей снова (F5), нажми Enter с пустой строкой и вставь следующую.

Переменные в строках: `{name}` ник, `{time}` время, `{date}` дата, `{rnd}` число 1–100, `{rnd:1-6}` своё.

## Важно
- Игра должна идти в режиме «окно» или «окно без рамки», иначе оверлей не будет виден.
- Программа ничего не вмешивается в игру: не жмёт клавиши и не читает память, только копирует текст. Правила конкретного сервера всё равно проверь сам.
- Данные лежат в `%APPDATA%\rp-overlay\rp-overlay.json`.

## Как получить exe
**Через GitHub:** залей все файлы в репозиторий, на вкладке Actions запусти «Build Windows EXE», скачай `RP-Overlay-Windows`.
**Локально:** установи Node.js 20, в папке выполни `npm install`, затем `npm start` (запуск) или `npm run dist` (exe в папке `dist`).
